Set up visit notifications

This makes a private key pair inside your browser. Nothing is sent or saved anywhere, so you're the only one who ever sees it.

  1. Tap Make my keys.
  2. In Render → your service → Environment, add two variables, copying each value with its Copy button: VAPID_PUBLIC_KEY and VAPID_PRIVATE_KEY. Save, then Manual Deploy.
  3. Close this page. Don't paste the private key into any chat, text or email.
